# SOC Operations, Krypton & Natas Cybersecurity CTF Labs

A searchable collection of [Learn SecByte](https://learn.secbyte.org/ctf/) exercises covering Security Operations Center (SOC) fundamentals, security signal investigation, Krypton cryptography challenges, and Natas web security levels.

This repository is designed for cybersecurity students, CTF players, aspiring SOC analysts, and security learners who want structured practice with defensive operations and technical security challenges.

## Introduction

Practical cybersecurity learning involves both recognizing security events and understanding technical vulnerabilities. SOC exercises help learners explore alert handling and operational workflows, while Krypton and Natas challenges provide opportunities to practice cryptography and web security concepts.

Use this index to find relevant labs, organize your learning, and document your progress.

## Learning Path

1. **Understand SOC fundamentals:** Start with the blueprint and foundations labs.
2. **Explore analyst workflows:** Practice the SOC operations and signal-hunting exercises.
3. **Build cryptography skills:** Follow the Krypton challenges in numerical order.
4. **Study web security:** Work through the listed Natas challenge and document the concepts encountered.
5. **Review and reflect:** Record your approach, observations, lessons learned, and defensive recommendations where applicable.

## How to Use the Labs

1. Open a lab through its direct link above.
2. Follow the instructions and rules provided by the lab owner.
3. Keep notes on commands, investigation steps, clues, and concepts.
4. Attempt challenges independently before consulting hints.
5. Record what you learned and revisit difficult concepts.
